# Выезд Тройка

Калькулятор стоимости доставки и выезда мастера: маршрут по Яндекс Картам, формула «подача + км × цена за км», своя стоимость, ручной километраж, история заявок, тёмная тема.

Сайт: https://estark407-max.github.io/vyezd-troika/ (копия: https://vyezd-troika.pplx.app)

Статический сайт (HTML/CSS/JS), без сборки. Ключи Яндекс Карт — в `config.js`, ограничены по HTTP Referer в кабинете Яндекса.
